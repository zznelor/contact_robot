# Робот первого контакта

Пишет клиенту в мессенджер, как только в Битрикс24 появилась новая сделка. Менеджеру больше не нужно
искать клиента в WhatsApp и писать первым вручную.

Отправка идёт через [Орбиту](https://my-orbita.ru) — с номеров и аккаунтов мессенджеров вашей компании,
подключённых в Орбите.

## Что делает

1. **Новая сделка в Битриксе** → ищет номер клиента в WhatsApp, Max и Telegram (в заданном порядке)
   и отправляет первое сообщение по вашему шаблону.
2. **Номера нет ни в одном мессенджере** (или в контакте нет телефона) → переносит сделку на этап
   «Не нашёл мессенджер», чтобы менеджер позвонил.
3. **Клиент молчит N часов** → отправляет одно напоминание (можно выключить).
4. **Клиент ответил** → один раз отвечает по шаблону (можно выключить), дальше переписку ведёт менеджер.

Каждый шаг робот отмечает комментарием в ленте сделки. Сообщения уходят только в рабочее время
(по умолчанию 09:00–21:00).

В веб-панели видно все заявки и их статусы, есть кнопки «Повторить», «Остановить», «Клиент ответил»,
настройки, шаблоны, журнал и проверка связи. В панель входят по почте и паролю, роли — администратор
и оператор.

## Как поставить

Подробно, с нуля — в **[УСТАНОВКА.md](docs/УСТАНОВКА.md)**. Коротко:

**Попробовать на своём компьютере.** Сначала скачайте и установите бесплатный [Docker Desktop](https://www.docker.com/products/docker-desktop/), запустите его и дождитесь надписи **Engine running** — как это сделать, по шагам в [УСТАНОВКА.md](docs/УСТАНОВКА.md#установить-docker-desktop). Затем:

```bash
git clone https://github.com/zznelor/contact_robot.git first-contact && cd first-contact
cp .env.example .env
docker compose up -d app
docker compose exec app python -m first_contact setup-code
```

Откройте <http://127.0.0.1:8080>, введите код, создайте администратора и пройдите настройку в панели.

**Для постоянной работы — на сервере** (1 ядро, 1 ГБ памяти, Docker) с доменом или поддоменом:

```bash
git clone https://github.com/zznelor/contact_robot.git /opt/first-contact && cd /opt/first-contact
cp .env.example .env          # впишите DOMAIN=robot.ваша-компания.ru
docker compose up -d
docker compose logs app | grep "Код первого входа"
```

Откройте `https://robot.ваша-компания.ru`. Настройки с компьютера переносятся на сервер одним файлом.

В обоих случаях нужны Битрикс24 с правами администратора и аккаунт Орбиты с подключённым мессенджером.
Где взять ключи — **[docs/НАСТРОЙКА.md](docs/НАСТРОЙКА.md)**.
